# Enlaces — Iglesia Internacional Cordero de Dios

Página tipo Linktree con diseño **multipastel, minimalista con efecto granito (film grain) y mobile-first**, lista para alojarse gratis en **GitHub Pages** sin necesidad de compilación ni servidores.

## Características

- **Última Prédica destacada** con miniatura automática de YouTube.
- **Mini Test Interactivo ("¿Qué palabra necesitas hoy?")** de 4 preguntas que entrega un versículo personalizado y envía el resultado directo al **WhatsApp** de la iglesia.
- **Playlist CAP** en Spotify, WhatsApp, Instagram, Facebook, TikTok y Página Web.
- **Botón nativo de compartir** y diseño responsivo accesible (WCAG AA).

## Cómo actualizar la última prédica o la playlist

1. Abre `config.js` (incluso directo desde la web de GitHub con el botón de lápiz **Edit**).
2. Cambia `ultimaPredica.url` o `enlaces.spotify.url` y guarda los cambios (**Commit changes**).
3. En 1–2 minutos se actualiza automáticamente en `https://jamirou.github.io/linktreeiccd/`.
